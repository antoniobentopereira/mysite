# Bento's Playground

My little corner of the internet, at antoniobento.me.
Small experiments, games, tools and ideas, built to learn and to have fun.

Not live yet. Work in progress.

## Local checks (dev only)

```
npm install      # once: installs Playwright (test tool, not deployed)
npm run serve    # the site at http://localhost:8417
npm test         # opens the homepage in Chrome and checks the portals
```
