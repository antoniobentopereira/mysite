# Norte visual reference

Images supplied by Antonio (he has permission to use Norte's art). Use them as the style reference for the Norte Reveal: Hero (`n-becomes-rising-arrow.png`), Enter control lever (`mascot-arcade-lever.png`), star mascot Token, and the flat sticker Tokens.

Style notes: dark brown background (about `#4a2700`), warm yellows and oranges, thick black outlines, flat colour, playful hand-drawn shapes. The mascot is a spiky yellow star with a small face (dot eyes, pink mouth).

Reference only: not served on the site.
